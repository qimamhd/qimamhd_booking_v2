# Milestone 4 — Calm Command Center & Availability UX
The UI answers only three immediate questions: what is happening today, what is available, and what needs attention.

- Command Center: date, booking count, confirmed/operational, holds, attention, Quick Booking, Availability.
- Availability: date navigation, hall/capacity filters, status, one action, and an explainable suitable-slot suggestion.
- Available slot opens a prefilled Quick Booking popup; occupied slot opens its booking.
- Booking shows one short attention sentence; finance stays behind smart buttons and wizards.
- Rule: if a field is not needed for the next decision, it does not belong in the first viewport.
